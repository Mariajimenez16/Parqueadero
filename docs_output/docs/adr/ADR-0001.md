# Use layered architecture

- Status: Accepted
- Date: 2026-09-29

## Context
Architecture decisions are recorded to establish long-term engineering principles and maintain system clarity.

## Decision
Use layered architecture. Use a modular, layered architecture to keep the intelligence engine testable and maintainable.

## Consequences
- Every layer operates independently with clean interfaces.
- Upstream parsers and analyzers only inspect code; generators consume structured schemas.
- Docs remain strictly aligned with codebase evolution.
